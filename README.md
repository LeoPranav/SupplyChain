# SupplyChain — Logistics Billing Checker UI

A responsive web landing page for a **Logistics Billing Checker** concept, inspired by a clean editorial hero style with gradient bands and strong typography.

## Run locally

```bash
python3 -m http.server 4173
```

Then open: `http://localhost:4173`

## Notes

- Mobile + desktop responsive layout
- Sections aligned to billing-audit workflow: Extract → Check → Payout
- Includes concise D2C insight write-up (under 500 words)
